# 高阶预期协同程度（HECS）指标与资产定价——基于中国A股市场的实证研究

**作者**：Beryl Von  
**代码运行环境**：Python 3.11.4（依赖库见下文）

---

## 项目简介

本项目是本科学年论文的完整代码复现材料。论文在唐国豪等（2025）的研究框架基础上，引入“高阶预期协同程度”（Higher-order Expectation Coordination Score, HECS）指标，在中国A股市场沪深300与中证500成分股样本中，检验高阶预期分歧的定价能力。

**核心实证发现**：HECS在投资组合分析与Fama-MacBeth回归中均不显著（t = -0.59），表明在信息透明度较高的大中盘股市场中，高阶预期分歧难以成为主导定价力量。

### 数据文件清单及用途

| 文件名 | 内容说明 | 在代码中的用途 |
| :--- | :--- | :--- |
| `TRD_Nrrate.csv` | 无风险利率（日频，按月提取） | 计算个股超额收益率 `Excess_Return` |
| `TRD_Mnth.csv` | 月个股回报率（含回报率、市值、交易量、交易金额） | 核心因变量与市场变量来源 |
| `FI_T5.csv` | 财务指标（ROA、ROE、毛利率） | 构造盈利类特征 |
| `FI_T1.csv` | 资产负债率 | 构造杠杆特征 `LEV` |
| `FI_T4.csv` | 总资产周转率 | 构造营运效率特征 `ATO` |
| `FI_T10.csv` | 账面市值比 | 构造价值因子特征 `BM` |
| `FS_Comscfd.csv` | 经营活动现金流量净额 | 构造应计利润 `ACC` |
| `FS_Combas.csv` | 资产总计 | 构造总资产增长率 `IA` |
| `SPT_Trdchg.csv` | ST/*ST 历史状态变更记录 | 动态剔除ST期间的观测 |
| `AF_Forecast(11-18).csv` | 分析师盈利预测（2011-2018） | 构造信息不对称代理变量（分析师覆盖数） |
| `AF_Forecast(19-25)(1).csv` | 分析师盈利预测（2019-2025，第一部分） | 同上 |
| `AF_Forecast(19-25)(2).csv` | 分析师盈利预测（2019-2025，第二部分） | 同上 |
| `IDX_Chgsmp(11-13).csv` 至 `IDX_Chgsmp(23-25)(7).csv` | 指数成分股变更记录（沪深300/中证500） | 筛选目标样本（大中盘股） |
| `2011月换手率.csv` 至 `2015月换手率.csv` | 月度换手率（Wind导出） | 构造流动性特征 `TURN` |

**注意**：上述CSV文件均来源于CSMAR和Wind的付费数据库，仅用于学术研究目的，请勿二次分发。
