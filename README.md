# asset-pricing-HECS
# 高阶预期协同程度（HECS）指标与资产定价

本项目是本科毕业论文《高阶预期分歧与资产定价：基于中国A股市场的实证研究》的代码与数据复现材料。

## 项目简介
基于唐国豪等（2025）的研究框架，引入“高阶预期协同程度”（HECS）指标，在中国A股市场大中盘股样本中检验其定价能力。

## 文件说明
*   `HECS_thesis_code.ipynb`: 包含数据清洗、指标构造、实证分析全流程的Jupyter Notebook。
*   `data/`: 存放原始数据集（通过网盘链接获取）。
*   `results/`: 存放核心输出图表和表格。
